# BLADNA — 2-minute demo

**Before:** phone on Wi-Fi (imagery needs internet), Settings → Erase all progress, sign out, screen mirroring on.

| Time | Screen | Say / do |
|---|---|---|
| 0:00 | Splash → Welcome | "BLADNA — read the land, restore it. A geospatial game where the map is the world." Show the sign-in screen: "Accounts are ready for Firebase; today we play as a guest." **Continue as guest.** |
| 0:15 | The map | "Greater Tunis from space. One glowing pin — the Medina. The other places are still clues." Tap the **Medina** → panel: what you see, why it matters, sources with confidence labels. |
| 0:30 | Field Training | **Investigate** → sort 5 items (drag or tap; one deliberate mistake shows the gentle hint). "Sorting is where every waste route starts." Back to the map: **Borj Chakir is revealed**, with a trail line. |
| 0:55 | Borj Chakir | "This circle is approximate — we never draw a landfill boundary we haven't verified." **Where Does It Go?** → tap the Medina, tap Borj Chakir → straight-line distance, scored against ≈ 9.35 km, explained as great-circle, not road distance. Sejoumi is revealed. |
| 1:20 | Sebkhet Sejoumi | "A Ramsar wetland — flamingos, but also construction, wastewater and dumping on its shores." Run **Evidence Before Conclusions** quickly or show **The Wetland Next Door**: trace 8 points → area vs the Ramsar 2,979 ha. |
| 1:40 | Time Machine | Layers → **Compare 2016 ↔ 2024**, drag the slider. "Same sensor, same provider — but a difference is a question, not a verdict." |
| 1:50 | Field Evidence & close | Menu → My discoveries → Field evidence: "Photos with manual labels — the dataset a future on-device model needs. No model is installed, and the app says so." Back to the map: "Small choices. A living map." |

**If asked:** offline? — everything except imagery. AI? — a clean model interface and a real labelled dataset, no fake predictions. Accounts? — Firebase integration documented in `docs/FIREBASE_SETUP.md`.
